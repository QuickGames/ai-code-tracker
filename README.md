# AI Code Tracker

A Java library for tracking AI-generated code through explicit metadata and annotations.

## Project Status

Work in progress. The project is in its early stages and APIs are subject to change.

## Planned Features

- Java annotations for AI-generated code provenance
- AI model and generator metadata
- Code generation depth and human review status
- Analysis and reporting tools
